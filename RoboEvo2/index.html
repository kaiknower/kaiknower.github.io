When a robot policy fails, a coding agent repairs it, and each verified repair becomes a reusable skill and a demonstration for the next policy.

How it works ↓Results ↓Real-robot demos ↓
TL;DR

Policy failures tell a coding agent what to repair; verified repairs become agent skills and policy training data. Over rounds, the policy succeeds more on its own and the agent is called less, with no new human demonstrations.

Four stages, repeated every round.

      07 · What gets repaired

      Seven kinds of failure, one repair loop.

      ✕ Failure✓ Repaired

      Task grounding and sequencing LIBERO-PRO · Code

      When
      The program acts on the wrong object or misses a step.
      Change
      Skill arguments and step order; add intermediate checks.
      Case
      The first program grasps the orange juice; the revision grasps the butter.
      ✕ Failure✓ Repaired

      Grasp acquisition LIBERO-PRO · Code

      When
      The object is not retained after closing.
      Change
      Grasp alignment, depth and orientation. Edits bound_grasp.
      Case
      A lower contact point grasps the cream cheese.
      ✕ Failure✓ Repaired

      Collision-free motion RoboTwin

      When
      A path meets an obstacle or cannot be planned.
      Change
      Clearance waypoints; new approach and retreat directions.
      Case
      The retreat cannot be planned; a horizontal one away from the rack can.
      ✕ Failure✓ Repaired

      Contact and articulation LIBERO-PRO · Code

      When
      Contact with a handle, knob or pushed object is lost or never made.
      Change
      The contact mode. Edits bound_drawer_pull, bound_surface_stroke.
      Case
      Horizontal fingers behind the handle open the drawer.
      ✕ Failure✓ Repaired

      Placement and transitions LIBERO-PRO · Code

      When
      The object is released off target, or the retreat blocks the next step.
      Change
      Placement offset and withdrawal path. Edits bound_place, bound_transfer.
      Case
      Pick the black bowl next to the plate and place it on the plate.
      ✕ Failure✓ Repaired

      Temporal efficiency LIBERO-PRO · Code+ICL

      When
      Idle periods or slow phases use up the horizon.
      Change
      Shorten idle transitions and fit the phases into the remaining budget.
      Case
      With 35 of 400 actions left, the revision still places the sauce can.
      ✕ Failure✓ Repaired

      Policy orchestration LIBERO-PRO · Code+Policy

      When
      A policy call fails, or leaves the next step infeasible.
      Change
      Which steps go to the policy and how it is called. Edits vla_act calls and routing ρ.
      Case
      A code grasp replaces a policy call that left the bowl on the stove.
